# ADR-002: Next.js frontend

- Status: Accepted
- Date: 2026-08-31

## Context

Derived from the V1 Technical Specification (see docs/Opportunity_OS_V1_Technical_Specification.md §31).

## Decision

Build the operator/public UI with Next.js (App Router, React 18).

## Consequences

SSR-capable, file-based routing, strong ecosystem. Adds a Node build step for web.
