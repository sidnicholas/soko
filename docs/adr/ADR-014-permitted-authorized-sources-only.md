# ADR-014: Permitted/authorized sources only

- Status: Accepted
- Date: 2026-08-31

## Context

Derived from the V1 Technical Specification (see docs/Opportunity_OS_V1_Technical_Specification.md §31).

## Decision

Connectors must be official API, licensed feed, authorized connection, permitted fetch, or human-assisted.

## Consequences

No prohibited scraping; every observation carries provenance and reliability.
